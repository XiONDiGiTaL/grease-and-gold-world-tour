# GREASE & GOLD: WORLD TOUR

16-bit-style side-scrolling beat 'em up starring Ricky B, Johnny $alami and V.V.

**Play it:** open `index.html` in any browser (or enable GitHub Pages).

- Arrows/WASD move - Z attack - X special (30 HYPE) - Space jump - Enter confirm - Esc pause
- 3 waves through G&G Headquarters: guards, executives, the Corporate Heavy, and Ledger
