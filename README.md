# Grease & Gold: World Tour

An original, 16-bit-inspired side-scrolling beat 'em up built in Godot 4.

## Current milestone

Stage 1 — Grease & Gold Records Headquarters foundation:

- Ricky B movement, facing, collision and placeholder combat
- Walkable street bounds and solid environmental blockers
- Enemy body separation, combat-gate scaffolding and HUD scaffolding
- Data files for the Executive, Corporate Heavy and Security Guard
- Pixel-art import and animation requirements

## Run locally

1. Install Godot 4.3 or later.
2. Clone this repository with GitHub Desktop.
3. Import `project.godot` in Godot.
4. Open `scenes/main.tscn` and press **F6**, or press **F5** to run the project.

This foundation intentionally uses placeholder visuals. Finished production sprites must be authored as clean PNG animation assets; generated/cropped images are art-direction references only.
